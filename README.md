# Sketch CRM

Initial project foundation for a Vercel-friendly CRM with a clean SaaS shell and subtle sketch visual accents.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```
